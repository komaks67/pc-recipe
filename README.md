# PC Recipe（BTO・自作PC 構成診断サイト）

用途と予算から、BTO／自作PCのおすすめ構成を診断し、パーツの互換性・電源容量・ゲーム別fpsの目安をチェックできる、**サーバー不要の静的サイト**です（HTML / CSS / JavaScript のみ）。

## まず見てみる
- `index.html` をダブルクリックすると、そのままブラウザで動きます。

## 無料で公開する（GitHub Pages の例）
1. GitHub で新しいリポジトリを作る（Public）
2. この中身（`index.html`・`css`・`js`・`.nojekyll`）をすべてアップロード
3. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開されます
（Cloudflare Pages / Netlify でも、フォルダをそのままアップロードするだけで公開できます）

- 価格を確認できなかったCPU・グラボ（Intel第12・13世代の多く、RTX 40／RX 7000など）は「価格未確認」と表示し、**おまかせ提案・交換の提案には出しません**（自作ビルダーでは選べます）

## 価格の更新のしかた（公開後）
1. `tools/parts-prices.csv` の `price` を新しい金額にし、`checked` に確認日（例 `2026-12-01`）、`source` に出どころを書く
   - CPU・グラボで `checked` が空の行は「価格未確認」になり、おまかせ提案に使われません
2. BTOモデルは `tools/bto-models.csv` を編集（`updated` に確認日）
3. `node tools/update-prices.mjs` を実行 → `js/prices.js`・`js/bto-models.js`・`js/price-history.js` が作り直されます
4. 作り直されたファイルを**そのまま公開してOK**です（以前の「初期版に戻す」作業は不要になりました）

## ファイルの役割
| ファイル | 内容 |
|---|---|
| `js/config.js` | サイト設定・アフィリエイトID・価格が仮かどうか（**ここを最初に編集**） |
| `js/data.js` | パーツ、ゲーム、用語集、読みもの記事、BTOメーカー情報 |
| `js/engine.js` | 互換性チェック、電源計算、fps目安、おすすめ構成の自動生成 |
| `js/ui.js` | 画面の共通部品（ルーター、保存、リンク、用語ホバー、ダークモード） |
| `js/pages-*.js` | 各ページ（診断／ビルダー／BTO／アップグレード診断／ゲーム別fps／保存／読みもの） |
| `css/style.css` | デザイン |

## パーツを追加するには
`js/data.js` の各配列（`D.cpu`・`D.gpu` など）に1行足すだけで、画面にも自動で反映されます。
- `gs`（ゲーム性能）、`mt`（多コア性能）、`score`（GPU性能）は**相対的な目安**です。既存のパーツの値を見て、近い性能のものに合わせてください。

## 数字の考え方（サイトの「このサイトについて」にも書いてあります）
- 仕様（ソケット・消費電力など）は公式情報、性能の数値は**目安**です。
- fps は実測ではなく、`engine.js` の計算モデル（GPU側の上限とCPU側の上限から計算）による目安です。
- 実測データを使いたくなったら、`D.games` の数値を差し替えるか、ゲームごとの表を追加してください。

## 既知の制限
- 価格の**自動取得**・**価格履歴グラフ**・**セール情報の自動集約**は未実装です（第3弾の予定）。
- 掲示板・レビュー投稿は未実装です（ログインが必要なため後回し）。
- ページの切り替えにURLの `#` を使うため、検索エンジンの表示（SEO）は弱めです。読みものを増やす場合は、記事を個別のHTMLにすると有利です。
- 保存はブラウザの中だけです（`localStorage`）。共有URL・ファイル書き出しも使えます。

## 価格の更新手順（手作業 → 自動化できる形）

1. `node tools/update-prices.mjs --init` … 今のパーツ一覧から `tools/parts-prices.csv` の雛形を作ります（初回のみ）
2. CSV を Excel / スプレッドシートで開き、`price` 列を最新の金額にして「CSV(UTF-8)」で保存
3. BTOモデルは `tools/bto-models.csv` に1行ずつ追加（maker は dospara / pckoubou / tsukumo、cpu と gpu は `data.js` のID）
4. `node tools/update-prices.mjs` … `js/prices.js` と `js/bto-models.js` が作り直されます（IDや金額が間違っていると、場所を教えて止まります）
5. `js/config.js` の `priceIsPlaceholder` を `false` にする

（自動実行の仕組み（GitHub Actions）は、今のリポジトリには入っていません。手元で 4 を実行してください。）
将来、アフィリエイト会社の商品データ（API/フィード）が使えるようになったら、その結果を同じ形のCSVに書き出す処理を足せば、完全自動にできます。

**注意:** 確認していない価格やモデルを入れないでください。サイトには「価格確認日」が表示されます。

## パーツ追加（DDR4 / AM4 / LGA1700 まで対応）

- CPU 55種（Ryzen 9000・7000・5000、Core Ultra 200S、Core 第12〜14世代）、GPU 31種（RTX 50・40、RX 9000・7000、Intel Arc B570/B580）、マザーボード 28種、メモリ（DDR4・DDR5）、SSD、電源、ケース、クーラーを増やしました
- 互換チェックが次のものに対応しました: DDR4/DDR5の取り違え、LGA1700のDDR4/DDR5ボード、内蔵グラフィックスなしCPU（F型番など）、A520と高出力CPU、BIOS更新が必要になりやすいCPU、第13・14世代の不安定問題の注意
- AM4 / LGA1700 は「新しいCPUが出ない世代」として、おまかせ構成ではほんの少しだけ不利に扱います
- `node tools/update-prices.mjs --init` は、入力済みの価格を消さずに、増えたパーツの行だけを足します

### 注意（スペックの確かさ）
- 性能の目安（gs / mt / score）は、相対的な見積もりです（公式の数字ではありません）
- Ryzen 9000 の型番・コア数・TDP は、AMDの製品一覧の掲載を確認しました。それ以外（Intel第12〜14世代、Core Ultraの非K型番、各GPUのTGP・長さ・厚み）は、一般に知られた仕様をもとにした目安です。購入前に、必ずメーカーの公式ページで確認してください
- RTX 30 / RX 6000 は、新品での入手が難しいため入れていません（アップグレード診断の「今のPC」の選択肢にはあります）
- RTX 50 SUPER は、確認した時点で未発売のため入れていません

## 第5弾: サーバー用PC診断 / ゲーム追加 / パーツ写真

### サーバー用PC診断（`#/server`）
- ARK（Ascended / Evolved）、Minecraft Java版（MOD入り）、Palworld、Terraria、Valheim、Rust、7 Days to Die に対応
- ゲーム・人数・MODの量・同時に動かすサーバー数から、**必要なメモリ**と**CPUの1コアの速さ**の目安を出し、3つの構成（買うとき最安／3年間の合計が最安／余裕あり）を提案します
- 24時間つけっぱなしの**電気代**（`config.js` の電気代単価で計算）と、本体＋電気代の3年間合計を表示
- 内蔵グラフィックス付きCPUを優先し、グラボなしで組みます。24時間動かすため、不安定問題のある第13・14世代の一部CPUは除外します
- 必要スペックは `js/pages-server.js` の `D.servers`（`ram` `per` `gs` `mt` など）を書き換えると調整できます。**公式情報と各社の公開情報にもとづく目安**で、Terraria・Valheim などは軽さを考えた推定を含みます

### 遊ぶゲームの追加（fps診断）
- ARK Ascended/Evolved、Minecraft、Valheim、Rust、7DTD、ELDEN RING（60fps上限）、BG3、黒神話、OW2、Marvel Rivals、BF6、Warzone、PUBG、HELLDIVERS 2、LoL、GTA V を追加（計26本）
- 追加分のfpsは計算モデルによる目安で、実測ではありません（`D.games` の `g / c / k` で調整できます）

### パーツ写真（楽天API・任意）
- 写真は `js/images.js` に入れたときだけ表示されます。**空のままなら、これまでどおり文字だけ**で動きます
- 取得: `RAKUTEN_APP_ID` / `RAKUTEN_ACCESS_KEY` / `RAKUTEN_REFERER`（楽天に登録したサイトURL）を環境変数にして `node tools/fetch-images.mjs`
- GitHub では Settings → Secrets に同じ3つを登録し、Actions の「fetch-images」を手動実行すると `js/images.js` が更新されます（キーはサイトのファイルに書きません）
- 写真が入ると、フッターに「Supported by Rakuten Developers」と著作権の表示が出ます。Amazonの商品画像は使っていません
- 型番が合わない商品は写真に使いません。合わないものは `js/images.js` を手で直せます

## 第6弾: 今のPCから診断（`#/mypc`・Windows向け）
- **① 読み取り**: 「ブラウザで仮読み取り」はGPU名だけ分かります（CPU名・メモリ量はブラウザから取れません）。正確に読むときは、PowerShellの確認用スクリプトをコピーして実行 → 出てきた文章を貼り付けます（`PCRECIPE1` から始まる形式。読み取るだけで、送信しません）
- **② 手直し**: 読み取り結果は選択欄に入ります。サイトのデータにないパーツは、近いものを手で選べます
- **③ 替えたいパーツ**（GPU / CPU / メモリ / 電源）を選ぶと、候補・費用の目安・互換性（電源・コネクタ・ソケット・DDR規格・クーラー）を表示
- 旧世代GPU（GTX 1650、RTX 2060〜3080、RX 580〜6800 XT など）を追加。性能値は相対的な見積もりです
- 電源の容量はWindowsから読めないため、手で選びます
- スクリプトは `js/pages-mypc.js` の `PS` にあります（実機のWindowsでの動作確認が必要です）

### CPUの追加（第7弾）
- 買う候補として、53個を追加（Intel 第12〜14世代のi3/i5/i7/i9の全モデル（F・K・KF・KS）、Core Ultra 200S の追加分、Ryzen 3000〜5000の追加分、Ryzen 8000G・8400F）。CPUは合計108個
- 「今のPC」として選べる旧世代を28個追加（Intel 第6〜11世代、Ryzen 1000〜3000）。これらは新品がほぼ売られていないため、買う候補には出しません
- 価格・性能値は目安です（`tools/parts-prices.csv` で価格を更新できます）
- 第13・14世代のi7・i9は、不安定問題の報告があるため `unstable: true` を付け、サーバー診断の候補から外しています

### 旧世代CPUを買う候補に追加（第8弾）
- Intel 第6〜11世代、Ryzen 1000〜3000 の28個を、自分でパーツを選ぶとき（組み立て画面）に選べるようにしました（`legacy: true`）
- 中古・在庫限りが中心で価格がぶれるため、**おまかせ提案・サーバー診断・CPU交換の提案には出しません**
- 必要なマザーボードを追加（LGA1200: H510/B560/Z590、LGA1151: B365/Z390、LGA1151第6・7世代用: B250/Z270、AM4: B450）。ソケット `LGA1151-v1` は第6・7世代専用で、第8・9世代用とは別物です
- 互換チェックを追加: Ryzen 1000/2000 は A520/B550/X570 不可、Ryzen 5000×B450 はBIOS更新、第6・7世代とRyzen 1000はWindows 11公式非対応、第11世代×H510などはPCIe 4.0不可
- 価格は目安です（`tools/parts-prices.csv`）
